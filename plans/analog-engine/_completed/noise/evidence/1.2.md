## Implementation

- `_scheduleVoice()` creates one ownership record before setup. It owns sources, started/ended/disconnected source state, graph nodes, parameter cleanups, start time, and release state.
- Nodes are registered immediately after creation through `ownNode()` before parameter configuration; the routing chain remains separate from ownership.
- One idempotent teardown path attempts all cleanup through a small best-effort helper, finalizes tracking, logs unexpected cleanup failures, and retains started-source bookkeeping so unstarted sources are never stopped.
- Future-note cancellation and destruction clear source callbacks before stopping/disconnecting sources; active overlapping voices remain unaffected and stale callbacks cannot revive a voice.
- Whole-voice completion still waits for all owned sources before releasing shared nodes and resolving `finished`.
- Setup errors propagate unchanged while teardown failures are logged and do not interrupt later cleanup. Engine lifecycle boundaries use the same best-effort cleanup policy.
