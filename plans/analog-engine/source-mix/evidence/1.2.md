# Step 1.2 evidence — pitched sub source layer

- Status: **Verified**
- Scope: atomic synth-only sub implementation and Phase 1 exit gate. Phase 2 documentation, registered references, and human listening remain pending.

## Implementation and review findings

The optional canonical synth `sub` schema, fluent forms/aliases, native centered oscillator, independent pre-effects gain, shared detune trajectory, and existing LFO/MIDI binding paths are implemented. Static source gains are floored locally without mutating schemas. The no-sub path and noise path remain unchanged.

The review found one preexisting ownership defect in the Step 1.2 implementation: `SupersawSource` allocated its `AudioWorkletNode` and then could throw while resolving a parameter, before the wrapper reached the synthesizer's cleanup boundary. The constructor now releases the worklet port and disconnects the node while preserving the setup error. A targeted missing-parameter test covers this boundary. The expanded existing voice helper also now exercises actual main+sub sibling completion/cancellation, LFO and MIDI sub-gain bindings, and setup/start failure after main allocation. No additional runtime defect was found; the prior gap was test coverage rather than a newly introduced leak.
