- Status: **Verified**

## Implementation

Implemented optional synth-only `sourceGain` schema validation and serialization, sampler rejection, typed/default/gain-only/selector-plus-gain factory dispatch, existing single-slot resolution, MIDI gain context, source-local stereo-preserving gain wiring, LFO discovery and target binding, static-only negative coercion, and source-node/gain-stage cleanup ownership. Omitted schemas retain the original path. Main gain is placed before effects and shared amplitude ADSR; noise remains on its existing path. The public `synth` API is simplified to four overloads in order: `synth(type?: WaveformAlias, gain?: SingleSlotAudioParamInput): Synthesizer`, `synth(type: SynthEngineAlias, gain?: SingleSlotAudioParamInput): UnisonSynthesizer`, `synth(type?: SynthSelector, gain?: SingleSlotAudioParamInput): Synthesizer | UnisonSynthesizer`, and `synth(gain: SingleSlotAudioParamInput): Synthesizer`; one-string numeric shorthand remains available. Runtime dispatch treats explicit `undefined` gain as omitted for valid selectors and the default selector, while retaining invalid two-argument validation. Selector recognition is data-driven through `synthEngineAliasMap` and the combined `synthSelectorAliasMap`; dispatch normalizes once and selects the canonical `"unison"` engine. The focused test iterates every registered engine alias.
