# Web Audio demos

Internal, focused browser-audio experiments for the Web Audio repository.

## Routes

- `/audio-clock` — clock events and audio-time scheduling
- `/midi` — Web MIDI manual verification
- `/scratching` — turntable-style retriggered sample playback

## Commands

Run commands from the repository root:

```sh
pnpm --filter demos dev
pnpm --filter demos check
pnpm --filter demos lint
pnpm --filter demos build
```
